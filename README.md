# Basic Python Calculator

## About

This is my first Python project.

It is a command-line calculator that performs:

- Addition
- Subtraction
- Multiplication
- Division

## Concepts Used

- Variables
- Functions
- Loops
- If-Else Statements
- Exception Handling
- User Input
- Float Data Type

## How to Run

```bash
python calculator.py
```
